# 固定评估提示词

`prompts.jsonl` 包含 10 条手写教学提示词：8 条悬疑小说改写，2 条普通文本任务。这里的“原模型基线”指当前本地的 post-trained `Qwen3.5-4B` 在尚未加载 adapter 时的输出，不是 `Qwen3.5-4B-Base` 模型。

每条记录包含稳定的 `id`、任务类别、`messages` 和人工检查项目。此文件只有输入，没有目标答案。基线完成后保留原文件；后续使用同一文件、同一推理配置测试 adapter。输出会保存提示词哈希，便于确认两次评估是否使用相同输入。

这些提示词用于观察风格和格式变化，不属于公开基准，10 条记录不能证明模型整体能力提升。后续教学训练集应另写故事片段，不能复制这些输入及其答案到训练数据。验证集与这里的固定测试集也应分开维护。

对每条改写结果人工检查：

- 人物、动作、说话者和悬疑信息是否忠于原文；是否添加了未经支持的解释或情节。
- 是否按照 `[角色][语气]正文` 输出，每行一个演绎单元。
- 语气标记是否有助于演绎，角色切换是否清楚，是否夹带了任务解释。
- 是否生成完整，`finish_reason=length` 表示触及本次输出上限，需要单独处理。

两条普通文本任务用来观察微调后是否将普通任务也强行套成剧本格式。先保存输出和人工笔记；自动打分留待定义好评分规则后再做。
