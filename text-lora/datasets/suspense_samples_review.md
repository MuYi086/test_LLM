# 悬疑风格样稿：监督摘要

用户目标：让恐惧悬疑小说更适合有氛围感的 TTS 朗读。本轮采用适度改写，事实与对白保留，氛围来自措辞、断句和语气。

30 条训练、10 条独立验证，完整模板最长 267 tokens；另外固定 10 条测试。全部为 agent 新写故事，用户风格决定尚未填写。

程序已检查角色、语气、人工声明的事实片段、台词归属和次数、来源隔离，以及离线训练模板。原文与改写稿经 agent 逐句复核；这些小规模合成数据仍是风格试验。

下面先展示五种情形，全部 40 条可在 Notebook 06 步骤 1 中展开。

## sus_train_01：门栓与无回应

原文：

虞桥把手电放在地上，向左拨开门栓。门只开了一指宽。他低声说：我在外面。里面没有人回答，门缝下的纸条却被收了进去。

改写参考：

```text
[旁白][压低]虞桥将手电放到地上，向左拨开门栓。
[旁白][紧绷]门开了。只有一指宽。
[虞桥][低声]我在外面。
[旁白][压低]里面没有人回答。门缝下的纸条，却被收了进去。
```

## sus_train_12：空白的末页

原文：

桑洛说：页数少了一张。守夜人问：你数过背面了吗？馆长抬起头：末页原本就是空的。桑洛把薄册翻到最后，背面的铅笔字没有被擦掉。

改写参考：

```text
[桑洛][紧绷]页数少了一张。
[守夜人][疑问]你数过背面了吗？
[旁白][压低]馆长抬起头。
[馆长][冷静]末页原本就是空的。
[旁白][紧绷]桑洛翻到薄册最后。
[旁白][压低]背面的铅笔字，并没有被擦掉。
```

## sus_train_16：未说出口的差异

原文：

贺蘅看着两张合照。左边的照片有七个人，右边只有六个。他心想，也许有人提前走了。他没有说出这个猜测，仍把两张照片并排放着。

改写参考：

```text
[旁白][冷静]贺蘅把目光停在两张合照上。
[旁白][紧绷]左边，七个人。右边，只有六个。
[旁白][压低]他心想，也许有人提前走了。
[旁白][冷静]这个猜测没有说出口。两张照片，仍并排放着。
```

## sus_train_22：迟迟不灭的灯

原文：

```text
[旁白][压低]深夜。温棋关掉台灯。墙上的光斑，还在。
[旁白][紧绷]她拔出插头。光斑没有缩小。
[旁白][冷静]窗帘合得很紧。地上的影子，只到她脚边。
[旁白][压低]房间里，没有人说话。
```

## sus_train_30：反复的提醒

原文：

[旁白][紧绷]祁知攥住扶手。
[祁知][压低]别往下看。
[孟榛][疑问]下面有什么？
[旁白][压低]祁知摇头。
[祁知][紧绷]别往下看。
[旁白][紧绷]孟榛停在第二级台阶。灯，照不到更低的地方。
